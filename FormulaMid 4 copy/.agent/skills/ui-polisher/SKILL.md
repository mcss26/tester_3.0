# UI Polisher Skill 🎨

**Authority**: Design System & Golden Standard Alignment
**Golden Reference**: `pages/admin/admin-master-proveedores.html`
**Golden Logic**: `assets/js/modules/admin/admin-master-proveedores.js`

This skill is responsible for the "fine details" of UI implementation. It ensures that every module feels part of a cohesive, premium application by enforcing strict adherence to the project's Golden Standard.

## 🏆 The Golden Standard Rules

Any module deviating from these rules is considered **NON-COMPLIANT**.

### 1. Page Structure (Macro)
The page **MUST** follow this exact hierarchy for state management to work:

```html
<main class="page-shell">
    <div class="page-card-wrap">
        <div class="page-card">
            <!-- 1. Loading Overlay -->
            <div class="page-card-loading" id="page-card-loading">...</div>
            
            <!-- 2. Empty State Overlay -->
            <div class="page-card-empty" id="page-card-empty">...</div>
            
            <!-- 3. Module Content (Wrapped) -->
            <div id="module-content">
                <div class="staff-dashboard">
                    <!-- Dashboard Content -->
                </div>
            </div>
        </div>
    </div>
</main>
```

### 2. Dashboard Header
Headers must use the "Soft" typography tokens and standard action buttons.

```html
<div class="dashboard-header align-start">
    <div>
        <h2 class="dashboard-title dashboard-title-soft">Module Name</h2>
        <p class="dashboard-subtitle dashboard-subtitle-soft">Short description sentence</p>
    </div>
    <button class="btn-icon btn-icon-flat btn-icon-plus" id="btn-new" aria-label="New Item">+</button>
</div>
```

### 3. Filter Bar (Compact)
Standard filter bar with status pills and search.

```html
<div class="filter-bar filter-bar-compact">
    <div class="filter-group">
        <button class="status-pill status-neutral topbar-pill topbar-pill-quiet filter-pill active" data-status="all">
            Total <span class="pill-count" id="count-total">0</span>
        </button>
        <!-- Additional Pills -->
    </div>
    <div class="filter-actions">
        <input type="search" id="search-input" class="input input-compact filter-input" placeholder="Search..." />
    </div>
</div>
```

### 4. Table Structure
Tables must be scrollable, sticky, and use padded cells.

```html
<div class="staff-list table-viewport table-shell" id="list-container">
    <!-- Injected by JS: -->
    <div class="table-scroll">
        <table class="table table-sticky">
            <thead>
                <tr class="table-head">
                    <th class="table-cell is-header cell-pad">Column</th>
                    <!-- ... -->
                </tr>
            </thead>
            <tbody>
                <!-- Rows -->
            </tbody>
        </table>
    </div>
</div>
```

### 5. Table Cell Styling
*   **Primary Text**: `table-cell cell-pad cell-strong`
*   **Secondary/Meta**: `table-cell cell-pad muted`
*   **Actions**: `btn-ghost btn-sm` (Never use `btn-primary` inside rows)

### 6. JS State Management
Logic **MUST** use the `setPageState` helper within the IIFE.

```javascript
function setPageState({ loading = false, empty = false } = {}) {
    if (loading) {
        ui.pageCardLoading?.classList.add('is-visible');
        ui.pageCardEmpty?.classList.remove('is-visible');
        ui.moduleContent?.classList.add('is-loading'); // Optional blur effect
    } else if (empty) {
        ui.pageCardLoading?.classList.remove('is-visible');
        ui.pageCardEmpty?.classList.add('is-visible');
        ui.moduleContent?.classList.add('is-hidden');
    } else {
        ui.pageCardLoading?.classList.remove('is-visible');
        ui.pageCardEmpty?.classList.remove('is-visible');
        ui.moduleContent?.classList.remove('is-hidden');
        ui.moduleContent?.classList.remove('is-loading');
    }
}
```

### 7. Forbidden "Alien" Patterns 👽
*   ❌ **No Tailwind**: `flex`, `grid`, `mt-4`, `text-center` are BANNED. Use `main.css` classes (`row-flex`, `text-center` helper, `mt-2` is allowed only if in utility list).
*   ❌ **No Inline Styles**: `style="display: none"` is BANNED. Use `.is-visible` toggling.
*   ❌ **No Native Alerts**: `alert()`, `confirm()` are BANNED. Use `window.Toast` and custom modals.

## 🛠️ How to Align a Module
1.  **Wrap**: Ensure `#module-content` wraps the dashboard.
2.  **HTML Polish**: Replace header classes with `dashboard-title-soft`, buttons with `btn-icon-flat`, inputs with `input-compact`.
3.  **JS Refactor**: Implement `setPageState` and `ui` object grouping.
4.  **Verify**: Check loading animation and empty state overlay positioning.
