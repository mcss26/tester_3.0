# Brief: Reporte General de Estado UX

## Objetivo

Generar un reporte completo del estado UX del proyecto FormulaMid.

## Instrucciones

1. Escanea todas las paginas HTML en `pages/`
2. Para cada modulo (admin, encargados, logistica, operativo, staff, publico) lista las pantallas, si tienen JS module asociado, y si el breadcrumb/topbar es consistente
3. Identifica paginas huerfanas (sin link desde su index)
4. Propone un plan de tests E2E con Playwright para las pantallas mas criticas

## Output

Guarda el reporte en `docs/_generated/orchestrator/ux-state-report.md`
